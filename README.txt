ADMINISTRATION
1. Ouvre le site.
2. Va à "Administration" en bas.
3. Le code actuel est : SaintMarc1984
4. Tu peux ajouter actualités, anniversaires, photos (par URL), vidéos et promotions.
5. Les données sont enregistrées dans le navigateur du téléphone.
6. Utilise Exporter/Importer pour sauvegarder les données.

IMPORTANT
Le stockage local est volontairement une étape intermédiaire : il permet de tester et gérer le contenu depuis le téléphone. Une fois le domaine et l'hébergement choisis, nous connecterons le site à une vraie base de données en ligne afin que les nouvelles publications soient visibles par tous les visiteurs et restent disponibles même si tu changes de téléphone.
